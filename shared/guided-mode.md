# Guided Mode

> 通用摘要（旧版精简）。**领域权威版本**：`domains/yuhong/references/guided-mode.md`（含逐阶段流程与组件选择规则）。本文件只作通用入口提示，细则以领域文件为准；两处不一致时以领域文件为准。

Use Guided Mode before building or editing PPT files.

## First Response

The first response should include:

1. Recognized client, industry, deck type, and audience.
2. Selected domain skill.
3. Selected template or template candidates.
4. Selected component store or component candidates.
5. Missing data, assets, or decisions.
6. Recommended outline.
7. Next-step menu: Continue / Go deeper / Replace / Build.

## Modes

- Continue: accept the current direction and proceed to the next planning step.
- Go deeper: add diagnosis, component rationale, data field checks, or page-by-page detail.
- Replace: swap the selected domain skill, template, component, or outline section.
- Build: create or edit PPT only after the user explicitly confirms.

## Guardrails

- Do not build slides in the first response.
- Do not choose visual components before identifying the business question.
- Do not mix domain language across UFS and Yuhong unless requested.
- Do not invent missing data.
- Prefer template inheritance and editable PPT elements over generic rebuilds.
