# 通用 PPT 设计规范（V0.3）

> 定位：**跨领域通用**的演示文稿视觉/版式设计规范。不绑定任何单一领域（雨虹/UFS/客户分析都是本规范的实例）。
> 用途：作为所有课件/汇报/复盘 PPT 的视觉设计依据；领域只填充"可配置令牌"（层 2），不重写规则。
> 执行路线（适配两 Agent 主线，见 `docs/agent-boundary.md` 第 0 节）：本规范同时约束 Agent A（仓库侧：大纲、蓝图、内容数据化、预览渲染、验收）与 Agent B（PowerPoint 内 GPT + skill-bridge：原生插入组件、槽位替换、产出最终课件）。**最终课件默认在 PowerPoint GPT 中完成视觉执行**；仓库侧脚本（渲染/像素/溢出验收）只作替代验证，不替代用户目视。
> 与 `shared/quality-rules.md`（业务/模板/组件质量）互补，本文件聚焦**视觉与版式**；领域规则（如 `domains/yuhong/references/quality-check.md`、`acceptance-checklist.md`）优先于本通用规范。
> 外部依据（通用设计理论，非雨虹特有）：
> - Garr Reynolds《Presentation Zen》——极简、留白、一页一观点
> - Nancy Duarte——演示叙事结构
> - Robin Williams《写给大家看的设计书》——CRAP 四原则（对比/对齐/重复/亲密性）
> - Edward Tufte——数据-墨水比（删无信息装饰）
> - WCAG 2.x AA——文字对比度
> - 8pt 网格、60-30-10 配色法则——UI/版式通用惯例

## 层 0 · 设计原理（不变式）

这些是"为什么"，不随领域变化，任何设计决策不得违背。

1. **一页一观点**：每页只承载一个核心判断/问题；其余元素全部服务于它。禁止多任务堆叠。
2. **亲密性（Proximity）**：相关元素靠近成组，不相关元素拉开距离——用分组代替分割线。
3. **对齐（Alignment）**：全页元素对齐到统一网格，不允许随手摆放。
4. **对比（Contrast）**：核心观点通过与周围环境的反差凸显（字号/色彩/留白），而非靠装饰。
5. **重复（Repetition）**：同类元素（标题、卡片、列表、结论条）全课件同风格，形成系统感。
6. **留白是工具，不是目标**：功能性留白（分组、呼吸、聚焦）必须保留；**无功能死白**（内容不足却按满页排、栏内大片空白）必须消除。
7. **数据-墨水比（Tufte）**：删掉不承载信息的装饰（阴影、图标、渐变只在信息服务时才存在）。
8. **图优于表优于文**：能图形化表达关系（流程/层级/对比/路径）就不用纯文字列表；但教学页以"一页一任务"优先，不硬塞图表。

## 层 1 · 可量化排版规则（中立数值）

| 组 | 规则 |
|---|---|
| 版面利用 | 按页型分档：**内容页/结论页 70–90%**，提问/过渡页 55–70%；禁止"内容只占上半页、下半页空白" |
| 栏平衡 | 同页多栏内容高度差 ≤ 栏高 1/3；内容少的栏放大字号/行距或补教学落点，不靠空白 |
| 网格 | 8pt 基础网格；页边距全课件统一；栏 gap 统一（22–28px）；区块间距取 16/24/32 阶梯 |
| 字号 | 四级阶梯：标题 / 小节标题 / 正文 / 辅助；**全片禁用 <16px**；正文行距 1.4–1.55；核心观点字号 ≥ 正文 1.3× |
| 色彩 | 一页 ≤3 个语义色；主色 60% / 次色 30% / 强调 10%；正文对比 ≥4.5:1、大字 ≥3:1（WCAG AA） |
| 字体 | ≤2 个字体族（中文 1 + 西文 1）；同层级同字重同字号 |
| 形状 | 同页圆角统一；**阴影只用于可交互或层级强调块**，纯展示块不用投影 |
| 结构多样性 | 无连续 3 页同构；一页一主组件 + 至多一个辅助组件；卡片网格页 ≤ 每 5 页 1 次 |

### 页型分档说明（版面利用率参考）

| 页型 | 利用率 | 示例 |
|---|---|---|
| 提问/悬念页 | 55–70% | 大字问题 + 选项/表态区，留白承载"思考" |
| 内容/对比/诊断页 | 70–85% | 数据、对比、模型 |
| 结论/收束页 | 75–90% | 判断 + 行动承接，信息必须撑满 |

> 判断"死白"：某区域（栏、行、页下半部）空白占比 >40% 且不承担分组/聚焦功能 → 死白，需按层 1 规则处理。

### 文案规范（层 1 · 文本质量）

**平衡原则**：去掉 AI 味 ≠ 过度口语化，两端都不可取。
- ❌ AI 味：空洞强化词、无主语空话、排比强迫、总结癖、双倍强调、口号反问
- ❌ 过度口语化：俚语/网络词/随意化，失去专业判断感
- ✅ 目标：**专业判断句 + 具体对象 + 适度口语温度**。口语只用于"接话/举例"语境（如讲师引述学员反应）；标题与结论保持专业判断。

**七条检测（逐句/逐页过）**：

| # | 检测 | 判定标准 |
|---|---|---|
| 1 | 空洞强化词 | 赋能/抓手/闭环/沉淀/颗粒度/至关重要/不容忽视/显著提升 → 删或换具体行为 |
| 2 | 无主语无对象 | 问"谁、对谁、做什么"，答不出 = 空话 |
| 3 | 排比强迫 | 连续 ≥3 个"动词+名词"或"从…到…"且无信息增量 → 只留信息最全的一句 |
| 4 | 连接词与总结癖 | 值得注意的是/不难发现/综上所述/可以说/这意味着 → 删；每段/每页都总结 = 降一档 |
| 5 | 双倍强调 | 删一个强调词意思不变 → 删 |
| 6 | 句式指纹 | 任何句式（否定-肯定、从…到…、问句开头、排比三连）**连续 2 页标题重复 = 模式化**；同段内同构 ≥2 次 = 降档；全课件同类结构 >3–4 次/页 = 分流改式 |
| 7 | 口语化平衡 | 检查是否滑向俚语/网络词/随意化；口语只用于接话/举例，标题与结论保持专业判断 |

**句式指纹案例（仓库实测）**：雨虹"看趋势"材料中"否定-肯定"结构密度——内容稿「不是」×16 /「而是」×12 / 部分否定（不代表/不只是/不等于）×15；单页提示词 5/5/5；4 页样张标题中 **3 页同用"不是/不只是/不代表"结构** → 判定模式化，需分流。**句式本身无罪，密度才是信号**。

**范例对照（仓库实测）**：

| 人类味 ✓ | AI 味 ✗ |
|---|---|
| "县域不是房地产增量市场的简单替代，而是…复合市场"（判断句，单次使用有效） | "我们要深度赋能县域渠道，构建端到端的服务闭环"（空洞词堆叠） |
| "老板常见反应：'你说有复合市场，我的县还是没单。'"（接话语境口语，有信息有边界） | "说白了就是换了个玩法"（滑向随意化） |
| "机会并没有平均散落在所有乡镇"（有边界、有例外） | "值得注意的是，县域市场正迎来深刻的变革"（连接词 + 强调词） |

**改写四步**：
1. 空洞词 → 具体行为（赋能 → 帮网点卖出去、补货、找项目）
2. 加主语与场景（提升效率 → 业务员每次跑镇带一张乡镇名单和两个项目问题）
3. 加例外/边界（机会不平均 → 先判状态再盘区域）
4. 判断句替描述句、删双倍强调、**句式分流**（同结构连用 2 页以上改式）

## 层 2 · 可配置令牌（领域填充）

换领域只改本层，规则不变。

| 令牌 | 雨虹实例 | 说明 |
|---|---|---|
| 主色 / 强调色 | 红 `#E84C22` / 深红 `#B22600` | 主色用于强调词、关键图形、标题高亮；小号文字与徽标用深红（对比 6.6:1） |
| 中性色 | 墨 `#505046` / 灰 `#6F6F6A` / 底 `#F7F7F8` / 白 `#FFFFFF` | 正文/辅助/底色/卡片 |
| 语义辅助色 | 琥珀 `#FFBD47` 等 | 仅数据语义，不作装饰 |
| 字体 | 微软雅黑（中文 + 西文同族） | 标题/正文同族 |
| 页眉页脚 | 右上角品牌标记 + 统一页脚 | 每页继承 |
| 组件视觉语言 | 雨虹 7 组件（DC-01/02/03/04/17/20/08） | 其他领域用自己的组件库 |
| 页尺寸 | 16:9（1600×900 / 13.333×7.5in） | 全课件统一 |

## 层 3 · 检查清单（构建/评审逐项过）

**结构**
- [ ] 一页一任务；标题是结论/问题式
- [ ] 无连续 3 页同构；一页一主组件
- [ ] 卡片网格页 ≤ 每 5 页 1 次

**版面**
- [ ] 利用率达标（按页型分档）
- [ ] 多栏高度差 ≤ 1/3；无死白（无 >40% 无功能空白）
- [ ] 元素对齐网格；区块间距走 16/24/32 阶梯

**文字**
- [ ] 四级字号阶梯成立；无 <16px
- [ ] 重点词有对比（字号/色彩）；行距 1.4–1.55

**文案（七条检测）**
- [ ] 无空洞强化词（赋能/抓手/闭环/沉淀/颗粒度/至关重要…）
- [ ] 每句有主语有对象；无空话
- [ ] 无排比强迫（三连并列无信息增量）
- [ ] 无连接词与总结癖（值得注意的是/综上所述…）
- [ ] 无双倍强调；判断句替描述句
- [ ] 句式指纹：连续 2 页标题同句式 = 改式；否定-肯定结构全课件 ≤3–4 次/页
- [ ] 口语化平衡：口语只在接话/举例语境；标题与结论保持专业判断

**色彩**
- [ ] 一页 ≤3 语义色；60-30-10 成立
- [ ] 对比度：正文 ≥4.5:1、大字 ≥3:1
- [ ] 全部颜色落在令牌内（无硬编码杂色）

**组件与品牌**
- [ ] 匹配组件复制源页、语义不改写；容量超限拆页
- [ ] 品牌标记/页脚继承；无外部 Logo、无批量生成痕迹（HTML/截图压平等，见 `build-execution-contract.md`）

**验收**
- [ ] 溢出 0；讲师备注与学员页分离；最终用户目视（PowerPoint 内完成成品，仓库侧像素/渲染脚本只作替代验证）
