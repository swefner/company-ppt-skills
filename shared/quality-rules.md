# Quality Rules

Use these rules for all company PPT skills.

## Business Quality

- Write for the real audience, not for the agent or slide creator.
- Start each business slide with a judgment, not a topic label.
- Separate result, cause, structure, risk, and action.
- Make action pages inspectable with owner, target, metric, and time.
- Mark missing data instead of inventing figures.

## Template Quality

- Use the selected domain template as the visual base.
- Preserve source deck typography, footer, frame, and page rhythm.
- Duplicate source slides and edit inherited elements when possible.
- Do not turn domain decks into generic consulting dashboards.

## Component Quality

- Do not use components only because they look good.
- Do not force diagrams where a table is the right evidence surface.
- Do not use table-only pages when the page needs logic, structure, or path.
- Pair customer-list tables with a prior or adjacent segmentation logic.

## PowerPoint Plugin Quality

- Prefer GitHub-readable files and raw URLs over local Windows paths.
- In constrained PowerPoint ChatGPT sessions, start from the Hub prompt and registries.
- Build only after Guided Mode confirmation.
