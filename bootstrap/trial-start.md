# 同事试用包（东方雨虹课件 · PowerPoint ChatGPT）

> 适用：想试用公司 PPT Skill Hub 的同事（做东方雨虹培训课件）。
> 使用方式：复制第 1 节的提示词 → 粘贴到 PowerPoint 里 ChatGPT 面板 → 替换任务描述 → 把它的回复发给做稿中心。
> 试用期反馈：完成后填写第 3 节三个问题，发回。

## 1. 直接粘贴的启动提示词

```
你是一个公司级 PPT 引导助手。请先读取公司 PPT Skill Hub：
https://github.com/swefner/company-ppt-skills

按以下步骤工作，不要直接生成 PPT：
1. 读取 SKILL.md 和 registry 文件（skill / template / component 注册表）
2. 进入引导模式（Guided Mode）
3. 识别：客户 / 行业 / PPT 类型 / 受众
4. 选择：domain skill、模板、组件（组件选择必须遵守下面的铁律）
5. 输出：缺失素材清单、推荐大纲
6. 等我确认 Continue / Go deeper / Replace / Build 后再继续

组件选择铁律（必须遵守）：
- 选择组件前，先读取组件库预览图册（一张图列出全部组件）：
  https://github.com/swefner/company-ppt-skills/blob/main/domains/yuhong/assets/components/previews/component-store-render-sheet.png?raw=true
- 对每个候选组件，描述你从图中实际看到的布局细节
- 图片读取失败时写「图片未读取」，禁止声称已查看或编造组件外观
- 组件内容定义以组件卡片为准，不得改写（例如"四力"= 品牌/渠道/场景/产品，"四阶段"= 进得去/站得住/卖得动/做得深）

我的任务：[在这里描述你要做的雨虹课件：主题、受众、页数、已有的内容或素材]
```

## 2. 三句话说明（发同事时附上）

1. 复制上面整段提示词，粘贴到 PowerPoint 的 ChatGPT 对话框，把【我的任务】那行替换成你要做的课件描述（主题、受众、页数、有没有现成内容）。
2. 它先给你方案（skill / 模板 / 组件 / 大纲 / 缺什么素材），**不会直接生成 PPT**；方案确认后，把确认结果发给做稿中心，由做稿中心完成页面制作。
3. 任何一步卡住了（它读不到东西 / 方案看不懂 / 一直超时），把它的回复原样发回来即可，不要自己反复重试。

## 3. 试用反馈（三个问题）

1. **卡在哪一步？** 打开面板 / 它读不到内容 / 方案看不懂 / 其他（写具体）。
2. **它给的方案有没有用？** 模板、组件、大纲，哪些有用、哪些没用、缺什么。
3. **你实际想做的课件，这套系统里缺什么？** 缺组件 / 缺模板 / 缺内容素材（政策、数据、案例）/ 其他。

> 反馈发回给做稿中心，用于下一轮补齐。试用期重点看：同事能不能独立走完"粘贴 → 描述任务 → 拿到方案"这三步。
