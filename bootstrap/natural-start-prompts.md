# Natural Start Prompts

Use these prompts in PowerPoint ChatGPT sessions when starting from the Company PPT Skill Hub.

## General Start

```text
请使用公司 PPT Skill Hub 帮我判断这次 PPT 应该怎么做。

项目背景是：[客户/行业/任务简单描述]
目标受众是：[老板/经销商/内部团队/学员]
我想做的是：[月会复盘/培训课件/案例分享/经营诊断/行动计划]

请先不要生成 PPT，先进入引导模式：
1. 判断应该使用哪个领域 skill
2. 推荐适合的模板
3. 推荐适合的组件
4. 告诉我还缺哪些数据或素材
5. 给出一个初版大纲

Skill Hub 地址：
https://github.com/swefner/company-ppt-skills
```

## Short Daily Start

```text
请使用公司 PPT Skill Hub 进入引导模式，先帮我判断这次 PPT 应该用哪个行业 skill、模板和组件，不要直接生成 PPT。

Skill Hub：
https://github.com/swefner/company-ppt-skills

我的任务是：[在这里描述你要做的 PPT]
```

## Expected First Response

The assistant should not build slides immediately. The first response should include:

- recognized client, industry, task type, and audience
- selected domain skill
- selected template or template candidates
- selected component store or component candidates
- missing data or assets
- first outline
- one of Continue / Go deeper / Replace / Build as the next-step menu
