# Visit / Lead Effect Curve

- ID: `visit-lead-effect-curve`
- Tier: first
- Source slide: cherry-red Slide 111
- Component role: execution-effect judgment

## Decision Trigger

Use when the page must answer:

拜访和商机是否真正产生推进效果？

## Best Fit

- Visit funnel.
- Opportunity conversion.
- Lead follow-up.
- Lost-customer recovery chain.

## Use When

- Visit activity must be connected with business outcome.
- There are stages such as lead pool, effective visit, opportunity, order, repeat, or recovery.
- The deck must avoid reporting only "visited or not".

## Do Not Use When

- There is no reliable visit or lead-stage data.
- The page only needs owner-by-owner task status.
- Visit activity is not a meaningful driver for the month.

## Required Data

- Visit pool count.
- Effective visit count.
- Lead judgments.
- Conversion, repeat purchase, or recovery result.
- Owner and next action when available.

## Monthly Review Mapping

- 拜访覆盖效果.
- 商机转化.
- 断采/下降客户追回.
- 客户开发周期.

## Replacement Method

- Show pool -> visit -> opportunity -> order/repeat/recovery.
- Highlight the bottleneck.
- Add 1-2 representative customers or examples.
- End with the next inspection action.

## July Nanchong Example

Use for the 8 月断采/下降客户追回 page if visit or recovery-stage data exists. If only customer sales decline is available, use a recovery action table instead and mark visit-stage data as missing.

## Risk

It can overclaim conversion if only visit counts exist. Treat it as coverage logic unless conversion or recovery data is confirmed.
