# Stage Path / SKU Deepening

- ID: `stage-path-sku-deepening`
- Tier: first
- Source slide: cherry-red Slide 59
- Component role: path judgment

## Decision Trigger

Use when the page must answer:

一个专项从拉升到稳定，下一步应该怎么推进？

## Best Fit

- Jiale special review.
- SKU deepening.
- Customer cultivation.
- Visit-to-repeat route.

## Use When

- There is a sequence from trial to repeat to deepening to stable purchase.
- The page needs to translate results into an operating route.
- Each stage can identify customer type, action, and check metric.

## Do Not Use When

- The page's real job is only to list customer names.
- There is no stage logic.
- The page only explains target completion.

## Required Data

- Stage labels or customer-stage classification.
- Jiale sales.
- Jiale share.
- SKU count or SKU depth.
- Customer groups by stage.
- Actions and check metrics by stage.
- Optional top Jiale SKUs and responsible owners.

## Monthly Review Mapping

- 家乐专项.
- SKU 做深.
- Jiale customer cultivation route.

## Replacement Method

- Use 3-5 stages as the main path.
- Under each stage, state customer object and action.
- Add 2-3 KPI anchors on the side.
- End with a boss inspection sentence.

## July Nanchong Example

Stages:

- 试购期：让新增/恢复客户完成首轮 SKU 试采.
- 复购期：盯 7 家大户至少 5 家复购.
- 做深期：高总采低家乐客户提高家乐占比.
- 稳定期：把 7 月拉起来的家乐销售稳在 6 万以上.

## Risk

It can become an inspirational route page. Always connect it to named customers, targets, owners, or inspection metrics.
