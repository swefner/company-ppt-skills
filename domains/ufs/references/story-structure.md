# Story Structure

## Default Monthly Review PPT

1. 封面
   - Dealer, month, project name.
2. 一页核心结论
   - One sentence: this month is good / mixed / risky and why.
3. 核心指标回顾
   - Sales, collection if available, active customers, new customers, Jiale.
4. 目标达成情况
   - Actual vs target for sales, active customers, new customers, Jiale if available.
5. 销售增长来源
   - Customer contribution, old/new/returning customers, high-value customers, product/SKU.
6. 客户结构与流转
   - Customer categories, value tiers, urgent customers, growth customers.
7. 家乐与 SKU 做深
   - Jiale amount/share/change, active SKU, Top SKU, Jiale SKU coverage.
8. 拜访与商机承接
   - Lead judgment groups and representative customers.
9. 下月行动计划
   - 3-5 action lines.
10. 复盘结论
   - What to keep, what to fix, what the owner should inspect.

## Narrative Variants

If data is very good:
- Start with result quality, then explain replicability.
- Avoid only celebrating; show which mechanism can be scaled.

If data is mixed:
- Start with headline result, then separate growth areas from hidden risks.

If data is weak:
- Start with target gap, then identify recovery priorities and inspection rhythm.

## Action Plan Format

Each action must have:

- Theme: 稳客户 / 承接新客 / 做深家乐 / 抓商机 / 提升拜访转化
- Target: customer group, SKU group, or lead group
- Owner: role or person if available
- Metric: sales, active customers, SKU penetration, lead conversion, visit result
- Deadline: week or month

## Strategic Co-Creation Structure

Use this when the user asks for 终端单店进阶、战略共创会、经营方向共识, or when the reference deck is 西安耀盛共创会.

1. 封面
   - Dealer, theme, meeting date.
2. 推进回顾与现状诊断
   - What has been explored, what has improved, what is not yet systematized.
3. 核心数据总览
   - Before/after or recent-period sales, active customers, Jiale, core customer indicators.
4. 模型判断
   - Whether the single-person/single-store model is running.
5. 人客品配能力诊断
   - 人: salesperson capability and management rhythm.
   - 客: target customer type, customer development path, customer tier.
   - 品: product portfolio, Jiale, opening product, add-on product.
   - 配: delivery/service model and efficiency.
6. 四大效率
   - visit efficiency, customer efficiency, product efficiency, delivery efficiency.
7. 战略方向与目标共识
   - What to scale, what to fix, which targets to set.
8. 落地推进计划
   - stages, owners, weekly/monthly review rhythm.

Do not mix this structure into a normal monthly review unless the user asks for a co-creation meeting.
