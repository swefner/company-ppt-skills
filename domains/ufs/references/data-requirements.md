# Data Requirements

## Minimum Input For A UFS Monthly Review

- Dealer/project name.
- Review month.
- Monthly targets:
  - sales target
  - collection target if available
  - Jiale target if available
  - active customer target
  - new customer target
- Sales detail or system export:
  - date
  - customer name/id
  - SKU/product name
  - amount
  - salesperson/owner if available
- Customer detail or customer rule export:
  - customer name/id
  - current owner
  - business scope
  - current category
  - value tier
  - suggested action
  - latest purchase date
  - current/previous sales if available
- Last month actuals or same system baseline.
- Last month action plan and execution status.

## Useful Optional Input

- Visit records:
  - visit date
  - merchant/customer
  - visit owner
  - communication
  - lead judgment
  - judgment reason
- SKU mapping:
  - Jiale flag
  - product category
  - key SKU / entry SKU / growth SKU
- Goal execution table.
- Team/task data:
  - task owner
  - assigned customer
  - feedback/result
  - next step

## Additional Input For Strategic Co-Creation

- Historical before/after data, preferably 6-12 months.
- Current operating model description:
  - salesperson/team setup
  - target customer type
  - visit route and cadence
  - product portfolio
  - delivery/service model
- Process metrics:
  - daily visit count
  - effective visit count
  - order conversion
  - repeat purchase
  - lead follow-up cycle
- Management mechanism:
  - weekly meeting rhythm
  - monthly review rhythm
  - target-setting method
  - incentive mechanism if available

## Missing Data Handling

- If SKU names are missing, do not create Jiale/SKU deepening pages.
- If customer-level data is missing, do not create tier migration pages.
- If visit records are missing, treat visit/lead pages as optional.
- If previous-month baseline is missing, use target achievement but avoid growth-source conclusions.
- If target values are missing, show actual result and mark target completion as not calculable.
