## Use

Use this file as the consolidated source template for Nanchong UFS monthly review pages.

Prefer this master template when the task is to:

- Select reusable Nanchong monthly review pages.
- Preserve UFS page frame, footer, typography, color, and table rhythm.
- Build a new monthly review by duplicating existing page patterns.
- Compare 4/5/6 month page evolution before choosing a component.

## Selection Notes

- Slides 1-14 preserve the April project-review structure.
- Slides 15-25 preserve the May project-review structure.
- Slides 26-40 preserve the June project-review structure.
- Do not treat all pages as equally reusable. Choose by business question first, then source month/page pattern.
- For complex logic pages, use `references/component-store/index.md` to decide whether a cherry-red component should supplement the UFS page frame.

## Build Rule

When creating a new deck from this template, duplicate source slides and edit inherited elements in place. Avoid rebuilding the page from scratch unless no source slide supports the required business question.
