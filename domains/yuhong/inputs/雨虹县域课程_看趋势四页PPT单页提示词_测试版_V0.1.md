# 一、四页整体教学逻辑

这四页共同承担“看趋势”板块的第一轮认知建立：

1. **第1页提出问题：**县城新房少了，县域建材生意还有没有机会；
2. **第2页从政策回答：**国家资源正在推动县城更新、乡村建设和品质建材下沉；
3. **第3页从市场回答：**需求没有简单消失，而是在改变发生位置和业务形态；
4. **第4页从消费回答：**乡镇市场的成交不仅取决于产品和价格，更依赖本地信任和服务确定性。

四页应形成连续叙事，不得制作成四张彼此独立的知识海报。

整体语气应从“县城新房减少带来的焦虑”逐步转向“重新看见县域机会”，但不使用夸大、煽动或空泛的激励性表达。

# 第1页｜认知提问页

## 1. 页面基础信息

- **页面编号：**M1-U1-01
- **所属模块：**模块一｜县域市场机会诊断
- **所属教学单元：**看趋势——县域机会为什么还在
- **页面任务：**提出问题、激活经验、暴露学员原有判断
- **页面类型：**互动问题页
- **建议组件方向：**大字问题＋三个现象线索＋现场选择区

## 2. 教学任务

从经销商熟悉的市场现象切入，让学员先表达自己对县域建材市场的真实判断，为后续政策、市场和消费变化的讲解制造认知入口。

本页只负责提问，不提前公布课程答案。

## 3. 学员可见内容

### 页面主标题

> 县城新房少了，县域建材生意还有没有机会？

### 三个现象线索

**县城端**  
新楼盘、新房交付和传统装修客流正在减少。

**乡镇端**  
自建房、翻修、维修和零散小工程仍在持续发生。

**经营端**  
不少经销商已经在做乡镇，但仍主要依赖熟人介绍和偶然订单。

### 现场选择

> 你现在更接近哪一种判断？

- A．县域建材需求正在明显萎缩；
- B．市场还有需求，只是越来越难找；
- C．机会仍然存在，但发生的位置和成交方式变了。

### 页面底部提示

> 先做判断，不急着找标准答案。

## 4. 信息层级

1. 第一视觉重点：主标题中的“还有没有机会”；
2. 第二层：县城端、乡镇端、经营端三个现实线索；
3. 第三层：A/B/C现场选择；
4. 页面底部仅保留轻量互动提示，不出现结论。

## 5. 排版要求

- 主标题应占据页面上方较大区域，形成明确的问题感；
- 三个现象不是三个普通功能卡片，应呈现为三个连续观察线索；
- A/B/C选择区域应清晰、便于讲师现场举手或快速询问；
- 可以适度使用县城住宅、乡镇自建房或经销商跑市场的真实场景图片，但不能抢占问题主体；
- 不要使用问号、灯泡、人物思考等通用装饰图标堆砌页面；
- 不得在本页出现“正确答案”“需求正在下沉”等总结性结论。

## 6. 互动设计

- **互动方式：**举手选择或现场快速询问；
- **建议时长：**2—3分钟；
- **讲师追问：**“你为什么这样判断？过去两年你所在县域最明显的变化是什么？”
- **互动目的：**让学员意识到自己可能长期只用县城新房和眼前订单判断整个县域市场。

## 7. 讲师备注

不要急着纠正学员，也不要在第一位学员回答后直接公布答案。先邀请2—3位学员简短分享，尤其关注他们判断市场时主要依据的是楼盘、门店、乡镇项目还是自身销量。

本页收束话术方向：

> 我们今天先不急着学怎么跑市场，先把视线从眼前订单抬起来。接下来从政策、市场和乡镇客户三个角度重新看一遍：县域的需求究竟是消失了，还是换了地方、换了形态、换了成交方式。

# 第2页｜政策证据页

## 1. 页面基础信息

- **页面编号：**M1-U1-02
- **所属模块：**模块一｜县域市场机会诊断
- **所属教学单元：**看趋势——县域机会为什么还在
- **页面任务：**把宏观政策翻译成经销商可理解的业务场景
- **页面类型：**政策方向与场景转译页
- **建议组件方向：**政策方向 → 业务场景 → 经销商关注点

## 2. 教学任务

让学员理解，看政策不是背文件、找补贴，而是判断未来哪些地方会发生建设、哪些房子需要改善、哪些需求可能持续出现。

## 3. 学员可见内容

### 页面主标题

> 看政策，不是找补贴，而是看未来哪些地方会发生建设

### 政策方向一｜县城和中心镇建设

**政策信号：**以县城为重要载体推进城镇化，完善县城和中心镇公共服务及基础设施。  
**可能场景：**县城更新、中心镇商业及公共设施升级、学校医院和公共空间改善。

### 政策方向二｜城市更新与既有住房改造

**政策信号：**持续推进老旧小区、危旧房、地下管网和既有住房改造。  
**可能场景：**旧房翻新、防水维修、渗漏治理、局部装修和给排水更新。

### 政策方向三｜乡村建设与宜居农房

**政策信号：**推进乡村建设、宜居农房、危房改造和农村人居环境改善。  
**可能场景：**农村新建房、原拆原建、自建房翻修、厨卫升级、外墙屋面及乡村小微工程。

### 政策方向四｜绿色建材下乡与县域商业建设

**政策信号：**推动品质建材、物流配送和商业服务能力向县域及乡镇下沉。  
**可能场景：**品牌产品进入乡镇、乡镇门店升级、仓储配送下沉、施工及售后服务下沉。

### 页面核心结论

> 政策不会直接变成订单，但会告诉我们：未来的建设、改善和服务需求可能在哪里出现。

## 4. 信息层级

1. 第一视觉重点：页面标题中的“看哪些地方会发生建设”；
2. 第二层：四类政策方向；
3. 第三层：每类政策对应的具体业务场景；
4. 底部结论完成统一收束。

## 5. 排版要求

- 不要把页面设计成政策文件目录或大段原文摘录；
- 页面核心关系是“政策方向如何转化成业务场景”，而不是四项政策的普通并列；
- 可使用从上至下或从左至右的转译结构，清楚呈现“政策信号 → 市场场景”；
- 四类政策可以适度分组，但避免做成四张内容拥挤的小卡片；
- “县城更新、旧房翻新、乡村自建、服务下沉”等场景词应成为视觉重点；
- 页面底部结论需要明显区别于政策说明文字；
- 不使用政府大楼、会议会场等与业务场景无关的通用政策图片。

## 6. 讲师备注

本页不需要逐条解读政策文件，也不要求学员记住政策名称。讲师需要反复完成一个动作：把政策语言翻译成经销商身边可能出现的房屋、项目、门店和服务需求。

需要强调：

- 政策方向不等于每个县、每个乡镇都会平均产生机会；
- 后续仍需要结合当地人口、建设、渠道和项目事实进行判断；
- 本页只回答“为什么值得重新向外看”，不在此处展开选镇方法。

# 第3页｜趋势对比页

## 1. 页面基础信息

- **页面编号：**M1-U1-03
- **所属模块：**模块一｜县域市场机会诊断
- **所属教学单元：**看趋势——县域机会为什么还在
- **页面任务：**解释县域建材需求发生位置和形态的变化
- **页面类型：**市场变化对比页
- **建议组件方向：**县城变化 → 需求迁移 → 乡镇及存量机会

## 2. 教学任务

帮助学员理解，部分县域新房市场减弱，并不代表建材需求简单消失；一部分需求正在转化为乡镇自建房、存量翻修、维修修缮和小微工程。

## 3. 学员可见内容

### 页面主标题

> 县城新房少了，不代表县域建材需求消失了

### 左侧｜县城正在发生的变化

- 新楼盘和新房交付减少；
- 传统新房装修客流下降；
- 部分装饰公司开始向乡镇寻找项目；
- 存量房翻修、维修和局部改造增加。

### 中间｜需求发生了两种变化

**发生位置变了**  
从只看县城，转向县城、中心镇、普通乡镇和村庄。

**业务形态变了**  
从主要依赖新房，转向新建、翻修、维修、更新和改善并存。

### 右侧｜乡镇正在出现的机会

- 农村新建、自建和原拆原建；
- 旧房翻修、加建和功能升级；
- 厨卫、屋面、外墙等局部改造；
- 厂房、学校、商铺等小微工程；
- 防水维修、渗漏治理和售后服务。

### 页面核心结论

> 经销商不能继续只等县城订单，而要主动沿着乡镇网点、工人和项目信息去找需求。

## 4. 信息层级

1. 第一视觉重点：标题中的“不代表需求消失”；
2. 第二层：县城变化与乡镇机会的左右对照；
3. 第三层：中间的“位置变了、形态变了”；
4. 底部落到经销商经营方式变化。

## 5. 排版要求

- 页面必须明确表达“变化”和“迁移”，不能只是左右两组普通列表；
- 左侧可以适当弱化，右侧乡镇机会应成为视觉重点；
- 中间使用清晰的方向、迁移或转化关系，但不要制作复杂抽象模型；
- 可使用县城住宅与乡镇自建房、翻修施工的真实场景对照；
- 图片必须服务于“需求位置与形态变化”，不得使用无关风景图；
- 不使用“县城衰退、农村崛起”等过度绝对化表达；
- 底部结论要自然引向后续“盘全域、选重点乡镇”。

## 6. 讲师备注

可结合访谈中的事实说明：

- 简阳经销商的乡镇业务占比已经较高；
- 周至的需求主要来自农村新建和存量房；
- 一些县域装饰公司已经开始向乡镇自建房寻找项目。

访谈事实用于说明部分县域已经出现变化，不能推导为全国所有县域完全一致。

本页收束时要强调：

> 机会并没有平均散落在所有乡镇。看见需求迁移之后，下一步还要盘清自己的县城和乡镇，找出最值得优先投入的区域。

# 第4页｜消费逻辑页

## 1. 页面基础信息

- **页面编号：**M1-U1-04
- **所属模块：**模块一｜县域市场机会诊断
- **所属教学单元：**看趋势——县域机会为什么还在
- **页面任务：**解释乡镇客户的购买决策和信任形成方式
- **页面类型：**消费决策路径页
- **建议组件方向：**品牌认知 → 本地信任 → 使用确定性 → 成交与口碑

## 2. 教学任务

帮助学员理解，乡镇客户并非只追求低价。由于防水、瓷砖铺贴等产品购买频次低、施工结果难以提前判断，客户真正寻找的是“有人推荐、有人施工、出了问题有人负责”的确定性。

## 3. 学员可见内容

### 页面主标题

> 乡镇客户买的不只是一桶材料，而是“出了问题找得到人”的确定性

### 客户为什么不容易直接做决定

- 产品购买频次低，自己不会判断；
- 材料效果通常要施工后才能看出来；
- 材料、施工方法和工人水平相互影响；
- 一旦漏水、掉砖或返工，损失远高于材料差价。

### 乡镇客户通常通过谁建立信任

**熟悉的门店**  
当地经营时间长，出现问题找得到人。

**熟悉的工人或包工头**  
懂施工，能够影响产品选择。

**亲戚、邻居和老客户**  
真实使用过，推荐更有说服力。

**本地样板和已完工项目**  
看得见效果，降低购买风险。

### 乡镇客户最终关心的五件事

1. 品牌靠不靠谱；
2. 当地有没有人用过；
3. 门店和工人敢不敢推荐；
4. 产品适不适合当前房屋和施工；
5. 施工与售后有没有人负责。

### 页面核心结论

> 品牌让客户愿意了解，本地的人、店和样板让客户真正下单；及时服务再把一次成交变成口碑和转介绍。

## 4. 信息层级

1. 第一视觉重点：“确定性”；
2. 第二层：客户为什么担心；
3. 第三层：信任通过谁形成；
4. 第四层：客户最终判断的五件事；
5. 底部结论收束为“品牌＋本地信任＋服务”。

## 5. 排版要求

- 页面应呈现一条清晰的信任形成路径，而不是三组彼此独立的列表；
- 可以从“购买风险”出发，经过门店、工人、熟人和样板，最终到达成交与口碑；
- 品牌是重要起点，但不能被设计为唯一决定因素；
- 可使用乡镇门店、工人交流、真实样板项目等场景图片；
- 不使用通用握手、盾牌、锁等抽象信任图片作为主体；
- 五项客户关注点可以作为路径中的判断节点，不必制作成五张重复卡片；
- 底部核心结论应成为全页最终记忆点。

## 6. 轻量互动设计

讲师在展示完整内容前，可以先提出一个口头问题：

> 如果一个乡镇业主准备做防水，最后真正影响他选择品牌的可能有哪几个人？

邀请学员快速回答，再按照门店、工人或包工头、亲友、老客户和样板项目的顺序展开页面内容。

如果PPT支持分步出现，可先展示问题与购买风险，再依次展示本地信任来源和最终结论；如果不支持动画，则保持页面完整展示，由讲师控制讲解顺序。

## 7. 讲师备注

本页不应被讲成“乡镇客户只认熟人”。需要强调：

- 雨虹品牌能够降低客户初次了解和接受的门槛；
- 但品牌要通过本地门店、工人、样板和服务，才能转化为真实成交；
- 经销商后续学习分销、工人运营、自建房和双包服务，本质上都在建设这些本地信任触点。

四页整体收束方向：

> 机会来源变了，机会位置变了，购买逻辑也变了。未来不是简单把货送到乡镇，而是要看懂需求在哪里发生、客户通过谁做决定、我们怎样被看见和被信任。

# 二、四页连续性检查

生成PPT后需要额外检查：

1. 第1页是否真正停留在提问，没有提前泄露后三页结论；
2. 第2页是否把政策翻译成了业务场景，而不是政策文件罗列；
3. 第3页是否清楚表现需求位置和形态的变化；
4. 第4页是否清楚表现乡镇购买中的本地信任路径；
5. 四页标题是否能够单独连成一条完整叙事；
6. 四页是否使用了不同但协调的页面结构；
7. 是否保持雨虹红、白、深灰的统一品牌风格；
8. 是否出现重复结论、重复图片或重复组件；
9. 是否存在内容拥挤、字号过小或卡片过多的问题；
10. 四页结束后是否能够自然进入“看现状”或“盘全域”模块。
