# PPT Skills 产品架构

> 产品视角的第一份架构说明（2026-08-15）。
> 本文件描述"公司级 PPT 制作产品"的整体图景，不绑定任何单一领域（雨虹/UFS 都是产品的内容案例）。

## 1. 产品定义

**一句话**：同事在 PowerPoint 里，用 AI 引导（ChatGPT/Basis Points）产出**有业务逻辑、有品牌、可编辑**的 PPT。

**产品价值**：把"业务判断 + 品牌视觉 + 可编辑交付"从个人经验变成可复制的方法论和机制。

**目标用户**：公司顾问/培训师（会 PowerPoint，非技术）。
**使用场景**：培训课件、经营复盘、案例分享、客户方案。

## 2. 五层架构

| 层 | 职责 | 现状 |
|---|---|---|
| 入口层 | 同事粘贴启动提示词 → Agent 进入引导模式 | ✅ `bootstrap/trial-start.md` 试用包 |
| 方法论层 | 引导模式（判断→规划→确认→构建）+ 防伪护栏 | ✅ 三轮 PowerPoint 实测验证 |
| 机制层 | 可执行组件体系：源页+槽位合同+渲染预览+导航索引+图册 | ✅ 骨架已成（支持数百组件规模） |
| 工程层 | COM 确定性构建 + 渲染 + 像素/溢出验收 | ✅ 14 页 Demo 跑通 |
| 内容层 | 领域资产（雨虹 7 组件/模板） + **通用逻辑层（空缺，见 §4）** | ⚠️ 通用层待制度化 |

## 3. 核心机制（产品的护城河）

护城河不是任何单一领域的模板或组件（那是内容），而是机制：

- **组件体系**：可执行组件 = 源页 + 槽位合同 + 渲染预览 + 索引导航 + 验收规则；"复制源页、替换命名槽位、不重画"是硬约束。
- **防伪护栏**：Agent 选组件必须读图册、描述真实布局、读不到写「图片未读取」、内容定义以卡片为准不得改写。三轮实测验证有效（先幻觉后真实）。
- **索引架构**：`component-index.json`（模式→模块→短名单）+ 模块图册，任何规模下 Agent 只面对 ≤10 个候选。
- **构建验收链**：内容数据化（JSON）→ COM 确定性构建 → 真实渲染溢出检查 → 像素级品牌继承验证。可重复、可自动验收。

## 4. 通用逻辑层（空缺项，待制度化）

**现状**：`domains/ufs/assets/reference-decks/cherry-red-logic-components.pptx`（141 页逻辑图形）是现成的跨领域逻辑母版，但目前只有 UFS 侧引用，没有产品级定位。

**定位**：通用逻辑层 = 跨领域可复用的逻辑表达（增长拆解、驱动板、矩阵、路径、漏斗等），不属于任何客户。

**规则（关键）**：
- 通用逻辑页**不是源页**——不直接复制进任何领域组件库（视觉不兼容、违反品牌契约）。
- 它是**逻辑参考**：从通用层挑页 → 定义决策组件卡片（业务问题）→ 重建到客户母版（雨虹/UFS/未来）。
- 决策组件（DC 卡片）是通用层与领域层之间的桥：卡片写"解决什么业务问题 + 用什么逻辑结构"，领域层负责"在客户母版上重建 + 槽位化"。

## 5. 领域孵化流程（新客户工厂）

雨虹走过的路就是产品的新客户工厂，制度化后任何客户照此进场：

1. **模板挂接**：客户模板 → 提取母版/品牌媒体 → 建立视觉底座
2. **组件化**：从决策组件卡片（业务问题→逻辑结构）→ 在客户母版上重建源页 → 槽位合同
3. **预览与索引**：渲染预览 → manifest 指纹 → 导航索引 → 模块图册
4. **护栏**：防伪条款随领域 Skill 启用
5. **交付物**：人用组件手册 + 领域 Skill 文档 + 注册表登记
6. **验收**：像素品牌继承 + 溢出检查 + 真实 PowerPoint 目视

## 6. 规模化路径

- 组件规模：索引 + 模块图册天然支持数百组件；候选 >10 时停下问人，不让 Agent 硬选。
- 领域规模：每客户一套领域资产（模板/组件/手册），共享方法论层与机制层；通用逻辑层跨领域复用。
- 入口规模：同事自助（PowerPoint Agent）由试用反馈驱动；做稿中心模式是当前已验证的主路径。

## 8. 决策记录（重要，勿凭直觉更改）

- **主路径是"做稿中心"还是"同事自助"**：当前做稿中心（同事用 Agent 出方案，做稿中心代做插入）；同事自助（Bridge 分发）待试用反馈验证需求后再定。证书/loopback 豁免等只发生在 Bridge 分发场景。
- **通用逻辑层不直接复制**：任何通用逻辑页进入领域组件库必须重建到客户母版（品牌继承契约）。
- **组件内容定义不可改写**：布局以预览图为准，内容以组件卡片+槽位合同为准（防伪护栏）。
